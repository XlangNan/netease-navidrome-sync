封面 / 歌词刮削

直接扫描你挂载的音乐目录(不经过 Navidrome),从网易云搜索匹配歌曲,把专辑封面嵌入音频文件, 歌词保存为同名 .lrc 文件放在歌曲同目录下。 这会直接修改你的音乐文件,建议先备份再正式跑。

网易云 API 代理

QQ音乐 / 酷我音乐 API 代理(Meting-API)

网易云搜不到精确匹配的时候,会自动依次试试 QQ 音乐、酷我音乐。留空则只用网易云一个源。

选择要扫描的目录

这里的目录是相对你挂载给本工具的那个音乐库根目录(docker-compose.yml 里 MUSIC_LIBRARY_DIR 挂的那个), 和 Navidrome 完全无关。留空就是扫描整个根目录。

刮削选项

方式一:手动挑选歌曲

先加载扫描目录下的歌曲列表,自己勾选要刮削哪些,比全自动扫描更可控。每一条也可以直接点「手动搜索」 单独确认封面/歌词,不用等自动任务跑完。

方式二:自动扫描整个目录

不用手动挑,直接把上面选的目录整个递归扫一遍处理。

方式三:自动监控新文件

持续盯着某个目录,有新的歌曲文件写入完成后自动刮削封面/歌词,不用手动跑。 适合配合下载工具或者网盘同步这种会陆续有新文件进来的场景。 只处理"启动监控之后新出现"的文件,已经在库里的歌曲不受影响(那是前面两种方式的事)。
